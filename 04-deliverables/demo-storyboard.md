# Three-minute demo storyboard

Status: built and locally verified; independent presentation assessment remains outstanding

| Time | Screen | Spoken point | Proof on screen |
|---|---|---|---|
| 0:00-0:20 | Decision card | “This is a hypothetical $5 million facility using MARA public filings. My recommendation is driven by the lowest of four caps and any hard blocker.” | Hypothetical label, requested amount, recommendation, binding cap |
| 0:20-0:50 | Obligor page | Explain primary repayment before collateral. State the current liquidity, debt, and cash-use tension without implying all assets are available. | June 2026 source rows and 2025 cash-flow row |
| 0:50-1:20 | Collateral waterfall | Keep quoted value constant. Show which fictional lots fail ownership, lien, control, or timing tests. | Eligible quantity, stressed price, each cost, available proceeds |
| 1:20-1:50 | Base availability switch | Change the repayment rail or earliest usable time. Show whether the collateral cap changes. | Before and after decision records; no wallet or transaction |
| 1:50-2:15 | Portfolio view | Add two fictional exposures. Show a shared Bitcoin, custody, or route concentration cap bind. | Concentration numerator, denominator, threshold, result |
| 2:15-2:40 | Opposing memo | Present the strongest objection and the best alternative structure. | One paragraph from CR-02 and reversal evidence |
| 2:40-3:00 | Source and question | Open one source row, state the largest unresolved gap, and ask for critique. | Source ID, retrieval date, limitation, reviewer question |

## Required visual

Use one waterfall or bridge from quoted collateral value to eligible stressed proceeds. A second small chart may show the four caps. Do not add price charts unless they explain the selected stress.

## Reviewer question

“Would you challenge the borrower analysis, the collateral-access blocker, or the portfolio cap first, and what evidence would change your view?”

## Failure handling

If Base does not change the outcome, say so and remove the switch from the final demo. If the decision is decline, present decline as the result rather than adjusting assumptions to force approval. If no external reviewer participates, label the opposing memo as self-review.
